## 二、正在进行时

### 1. TNC 后海湾湿地连续监测

**线索**
香港后海湾的基围（传统潮汐虾塘）是候鸟、马蹄蟹、鱼虾的栖息地。TNC Hong Kong 正在修复这片湿地生态，但面临一个核心问题：如何知道生态修复真的在朝着正确方向恢复？传统方法是每隔几周派人到现场采水样、送实验室等结果——每次只得到一个时间点的快照。然而湿地是高度动态的系统：潮汐每日进出、降雨数小时内改变盐度、池塘与海湾每月约换水 10 次重塑内部环境。两次采样之间，绝大部分变化未被记录。

**解决方案**

Seeed 产品 × 角色：
- **SenseCAP 4G Data Logger** — 数据采集与回传枢纽：收集各传感器读数，通过蜂窝网络持续上传至云端仪表盘，保证分布式监测点数据可靠流通（选 4G 是因为水质监测设备功耗较大，蜂窝比低功耗 mesh 更适合持续供电场景）
- **SenseCAP S700-C 七合一气象传感器** — 环境背景层：记录气温、湿度、气压、光照、风速风向、降雨，给水数据提供"为什么变化"的因果解释（如同样的盐度变化，暴雨后 vs 无雨周讲的是完全不同的故事）
- **抗腐蚀水质传感器阵列**（盐度 / 溶解氧 / 浊度 / pH / 水温）— 核心指标层：由 TNC 直接采购，Seeed 负责规格匹配与系统集成，其中多枚为专为长期盐水部署选型的抗腐蚀版本

解决的问题：TNC 的生态学家需要回答"湿地修复是否在正确方向恢复"，但传统采样只能每几周给一个时间点快照，而湿地是动态系统（潮汐 / 降雨 / 每月约 10 次换水），两次采样间绝大部分变化未被记录——生态学家实际上是在盲管修复项目。

达成结果：Phase 1 已部署运行。团队通过仪表盘实时看条件演变（每次换水如何改变池塘、潮汐如何与水位互动、热浪 / 风暴如何穿过系统），可实时发现并响应溶解氧骤降等事件而非事后发现，跨不同池塘区域生成可比数据集以揭示不同管理方式如何影响生态条件。Phase 2 规划 reCamera Pro 做自动鸟类多样性观测。

**案例**
- 地点：香港·后海湾基围湿地
- 合作方：The Nature Conservancy (TNC) Hong Kong
- 进展：Phase 1 已部署运行；Phase 1 blog 已写好（*Turning Environmental Monitoring into Conservation Evidence*）

### 2. 不丹全国老虎监测（RiKAnet）

**线索**
不丹需要在全国范围内进行老虎种群监测与追踪。传统 GPS 项圈覆盖范围有限、成本高，无法满足全国尺度的大面积监测需求。且不丹山区地形复杂、蜂窝信号不可靠，需要一套长距离、低功耗、可大范围铺设的通信网络来支撑全国老虎监测。

**解决方案**

Seeed 产品 × 角色：
- **Tracker** — 个体定位层：佩戴于老虎身上，提供 GPS 位置数据，实现个体追踪
- **LoRa / Mesh 网络设备** — 通信骨干层：铺设覆盖不丹全国的低功耗长距离 mesh 网络，解决保护区无蜂窝信号、地形复杂的长距离数据回传问题
- **reCamera（CV 个体重识别）** — 辅助识别层：通过端侧计算机视觉做老虎个体花纹重识别，配合项圈实现物理追踪 + 视觉识别的双重 ID

解决的问题：不丹的野生动物研究者需要在全国尺度上监测老虎种群，但传统 GPS 项圈覆盖范围有限、成本高，且不丹山区蜂窝信号不可靠，无法支撑全国连续追踪——研究者缺一套能覆盖全国无人值守区域的低成本追踪 + 通信方案。

达成结果：框架在建，尚无田野成果。

**案例**
- 地点：不丹（全国）
- 合作方：RiKAnet / 不丹 FabLab
- 进展：框架在建

### 3. Mothbox 开源 trap cam

**线索**
昆虫生物多样性监测需要低成本、可复制的相机陷阱（trap cam）工具。传统商用相机陷阱昂贵且封闭，数据需人工翻图识别，无法实时。研究者需要一套开源、可本地制造的 trap cam 用于蛾类及其他通用昆虫监测。

**解决方案**

Seeed 产品 × 角色：
- **reCamera** — 边缘 AI 视觉层：在相机陷阱上做端侧蛾子 / 昆虫识别与自动计数，无需人工翻图，实时出结果
- **LoRa** — 无线回传层：在无 WiFi / 蜂窝的野外环境传输识别结果与图像数据，实现无人值守远程监测

解决的问题：昆虫研究者需要低成本、可复制的 trap cam 做生物多样性监测，但传统商用 trap cam 昂贵且封闭，采集的图像要人工逐张翻看识别，既慢又不可扩展。研究者缺一套开源、可被 Fab Lab 本地制造、端侧 AI 自动识别的 trap cam。

达成结果：巴拿马 FabLab 已部署运行，开源设计可被全球 Fab Lab 网络复制，延展至秘鲁、黄石公园。

**案例**
- 地点：巴拿马→秘鲁 / 黄石
- 合作方：巴拿马 FabLab / mothbox.org
- 进展：巴拿马已部署运行

### 4. Mothbox 升级 / Interspecies Open Datalogger

**线索**
仅做蛾子 trap cam 不够——研究者和保护机构面临的不只是单个传感器问题，而是每次新场景都要从零搭一套 bespoke 系统的"重复造轮子"困境。他们需要一个模块化、多物种通用的开源平台，能快速接入不同传感器组合解决不同物种监测需求。

**解决方案**

Seeed 产品 × 角色：
- **Open Datalogger 中间件** — 连接层（核心交付物）：把感知（传感器）→ 边缘 AI → 回传 → 云各层串起来的开源中间件，使任意传感器可接入任意物种问题，研究者不需为每个新场景重复造轮子
- **reCamera** — 视觉感知层：端侧 CV 识别
- **LoRa** — 通信回传层：低功耗长距离无线传输

解决的问题：研究者和保护机构每次面对新物种 / 新场景都要从零搭建 bespoke 监测系统——选传感器、写驱动、搭回传、做识别，重复造轮子。他们缺一个模块化开源平台，能快速接入不同传感器组合解决不同物种问题，把基础设施变成可复用的连接层。

达成结果：初步合作框架已签。从巴拿马单一蛾子 trap cam 升级为可连接多模态传感器（CV / 声学 / 气象 / 追踪）的通用开放平台中间件。

**案例**
- 地点：巴拿马（原始 Mothbox 已部署）→ 全球
- 合作方：Dina Lab (Andy) / 巴拿马 FabLab
- 进展：初步合作框架已签，升级推进中

- **Seeed Fusion 量产制造能力** — 制造层：将 Robert Long 实验室自研的嗅觉传感器原型转化为可量产、可部署的产品，解决从原型到量产的工程化鸿沟（PCB 打样、元器件采购、组装测试、小批量到量产过渡）

### 7. 跨物种沟通 reButton

**线索**
跨物种沟通（人类-动物、动物-动物）需要带麦克风和扬声器的交互设备，使动物能通过声音参与双向沟通。FluentPet 在跨物种沟通领域有深厚积累，但缺一个开源的可编程硬件设备来实现这一交互。

**解决方案**

Seeed 产品 × 角色：
- **reButton** — 双向声音交互层：集成麦克风（捕捉动物声音输入）+ 扬声器（播放声音输出），实现人-动物、动物-动物的双向声音沟通接口

解决的问题：跨物种沟通研究需要一个硬件载体，既能"听"（收音）又能"说"（放音），使动物能通过声音参与双向交互。现有设备要么只收音不发音，要么不可编程、不开源，无法支撑灵活的沟通实验。

达成结果：待对接，尚无进展。

**案例**
- 合作方：FluentPet (Leo)
- 进展：待对接

### 8. CollarID 开源项圈

**线索**
动物个体识别与全生命周期追踪是动物研究的核心需求。传统方法（标记重捕、照片 ID、GPS 项圈）侵入性强、成本高、覆盖范围有限。需要一套开源、低成本、可多物种复用的项圈方案。

**解决方案**

Seeed 产品 × 角色：
- **Tracker** — 定位层：提供 GPS 位置数据，实现个体追踪
- **Meshtastic** — 通信层：低功耗长距离 mesh 网络，解决项圈在野外的数据回传
- **reCamera（CV）** — 识别层：通过计算机视觉做动物个体花纹 / 体貌重识别，配合项圈实现物理追踪 + 视觉识别的双重 ID
- **Seeed Fusion 小批量制造** — 制造层：将 MIT 的开源项圈设计通过 Fusion 小批量生产实现联名制造

解决的问题：动物个体识别与追踪是研究核心需求，但传统方法（标记重捕 / 照片 ID / GPS 项圈）侵入性强、成本高、覆盖范围有限。研究者缺一套开源、低成本、可多物种复用的项圈方案——MIT 有设计但缺制造能力，Seeed 的 Fusion 补上从设计到量产的链路。

达成结果：待启动，Fusion 制造 + 联名。

### 9. 反盗猎实时关键帧告警

**线索**
反盗猎场景的核心痛点是实时性：传统 SD 卡相机陷阱要数周后取回才能知道发生了什么，盗猎行为早已发生。需要一套能在 ~90 秒内检测并告警的系统——但野外环境带宽极低，无法传整段视频。

**解决方案**

Seeed 产品 × 角色：
- **reCamera** — 边缘 AI 检测层：在端侧实时检测可疑事件（盗猎者 / 车辆 / 异常活动），决定哪些帧值得回传
- **低功耗 mesh 回传** — 通信层：不传整段视频（带宽不够），而是低带宽只传边缘 AI 筛出的"可疑关键帧"，通过低功耗 mesh 网络回传，实现 ~90 秒级告警

解决的问题：反盗猎保护人员需要实时告警来当场阻止盗猎，但传统 SD 卡相机陷阱数周后才取回数据，盗猎早已发生。而野外带宽极低，无法实时传视频流。Seeed 的方案用边缘 AI 先在端侧筛出"可疑帧"，只传关键帧而非整段视频，在极低带宽下实现准实时告警。

达成结果：叙事框架已定（"90 秒 vs 数周 SD 卡"），尚无落地案例。需锚定 1 个命名参考部署（候选：犀牛角关键帧告警 / 雨林电锯检测）。

**案例**
